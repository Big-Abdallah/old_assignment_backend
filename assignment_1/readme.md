# JavaScript Assignment Solutions

A complete JavaScript assignment that covers core programming concepts, modern ES6+ features, and problem-solving fundamentals.

---

## 📌 Project Overview

This project contains solutions for:

### Part 1: Programming Questions

Includes practical coding tasks such as:

* Type conversion using `Number()` and `parseInt()`
* Checking falsy values
* Loops with `continue`
* `filter()`, `map()`, `reduce()`
* Spread operator
* `switch` statements
* Functions and arrow functions
* Object destructuring
* Promises / asynchronous JavaScript
* Array and object methods

### Part 2: Essay Questions

Short theoretical answers about:

* `forEach()` vs `for...of`
* Hoisting & Temporal Dead Zone (TDZ)
* `==` vs `===`
* `try...catch`
* Type conversion vs coercion

### Part 3: Bonus Question

Implemented a custom `createCounter()` function using **closures**.

Features:

* `increment()`
* `decrement()`
* `reset()`
